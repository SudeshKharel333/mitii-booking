# Mitii Booking

A hybrid PHP + React WordPress plugin for appointment booking. Customers pick a service and/or staff member, choose an available time slot, and book — as a guest or with an account. Site admins manage services, staff, working hours, and bookings from a custom dashboard inside wp-admin.

---

## Features

- **Two booking flows** — service-first (`[mitii_booking]`) and staff-first (`[mitii_booking_by_staff]`), sharing the same backend
- **Real availability, not a fixed schedule** — time slots are computed from each staff member's actual weekly working hours, minus their existing bookings, so double-booking is impossible
- **Admin dashboard** — full CRUD for Bookings, Services, and Staff, including image upload via WordPress's native Media Library and a weekly working-hours editor
- **Independent customer accounts** — register/login/logout, completely separate from WordPress user accounts, with guest checkout still available at every step
- **Customer portal** (`[mitii_customer_portal]`) — total spent, next upcoming appointment, and full booking history with self-service cancellation
- **Editable booking statuses** — admins can mark bookings as Pending, Completed, or Cancelled directly from the dashboard

---

## Tech Stack

- **Backend:** PHP, WordPress REST API, custom database tables (via `$wpdb`/`dbDelta`)
- **Frontend:** React + TypeScript, built with `@wordpress/scripts` (Webpack)
- **Auth:** WordPress's own password hashing (`wp_hash_password`/`wp_check_password`), custom cookie-based sessions for customers

---

## Installation

1. Clone or download this repository into `wp-content/plugins/mitii-booking/`
2. Install dependencies and build the frontend:
   ```bash
   npm install
   npm run build
   ```
3. Activate **Mitii Booking** from **Plugins** in wp-admin — this creates all required database tables automatically

---

## Usage

Add any of these shortcodes to a WordPress page:

| Shortcode | Description |
|---|---|
| `[mitii_booking]` | Public booking widget — service, then staff |
| `[mitii_booking_by_staff]` | Public booking widget — staff, then service |
| `[mitii_customer_portal]` | Customer login and "my bookings" dashboard |

The admin dashboard appears automatically under **Mitii Booking** in the wp-admin sidebar once the plugin is active — no shortcode needed.

**Optional:** for a distraction-free booking page with no site header/footer, select **"Mitii Booking (No Header/Footer)"** from the Template dropdown (Page Attributes, in the block editor sidebar) on any page using one of the shortcodes above.

---

## Development

```bash
npm run start     # watches src/ and rebuilds automatically while developing
npm run build     # one-time production build
```

Any change to a database table's structure (in `includes/class-mitii-activator.php`) requires deactivating and reactivating the plugin for it to take effect.
